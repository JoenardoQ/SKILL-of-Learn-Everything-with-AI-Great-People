# AI Learning Coach

[English](README.md)

AI Learning Coach 是一个面向学习者的 Codex Agent Skill。它适合希望真正理解知识、而不只是获得答案的人：从第一性原理建立基础，让你完成有意义的尝试，定位最早出现的理解缺口，并检查你能否独立迁移所学内容。

你可以用它学习概念、工程技能、数学论证、学术论文和社会现象，也可以用它练习与复习。

## 你会获得什么

- 根据学习目标和当前基础调整的学习路径。
- 在要求你使用陌生知识推理之前，先补充必要基础。
- 用少量综合问题代替冗长的碎片化问答。
- 保留有效思考空间的提示，以及之后全新的独立检查。
- 明确区分引导练习、独立迁移和闭卷提取。
- 当证据确实能够检验先前判断或信心时，选择性校准信念更新。
- 精读论文时区分作者主张、已检查证据、假设和未决问题。
- 分析社会现象时区分事实、因果解释、预测、诠释和价值判断。
- 暂停学习或更换 Agent 时，生成紧凑的交接记录。

如果你只想得到直接答案，教练不会强制启动教学流程。你随时可以明确要求直接回答。

## 在 Codex 中安装

让 Codex 从本仓库安装 Skill：

```text
使用 $skill-installer 安装
https://github.com/JoenardoQ/SKILL-of-Learn-Everything-with-AI-Great-People/tree/main/ai-learning-coach
```

安装后请新建一个 Codex 任务，让 Skill 在全新上下文中被发现。如需手动安装，请完整复制 `ai-learning-coach/` 目录到 `$CODEX_HOME/skills/ai-learning-coach/`，不要打平目录结构。

## 快速开始

显式调用 Skill，并说明你最终希望具备什么能力：

```text
$ai-learning-coach 帮我理解贝叶斯更新，使我能够解释医学检测结果。
假设我已经掌握基础概率。
```

教练通常会：

1. 识别你的学习目标和起点；
2. 选择教学模式，并限定一个可管理的学习阶段；
3. 提供下一步推理所需的基础；
4. 让你解释、预测、推导、求解或应用；
5. 定位理解缺口，并给出最小有效提示；
6. 用不同情境检查迁移能力，之后再进行闭卷提取。

学习节奏始终由你控制。你可以要求放慢速度、跳过已经掌握的内容、改变目标、查看完整示范或直接获得答案。

## 使用示例

### 学习概念

```text
$ai-learning-coach 从第一性原理教我数据库索引。我会写 SQL，
但不理解查询计划。
```

### 在实践中学习

```text
$ai-learning-coach 通过制作一个可筛选列表教我 React 状态管理。
在我尝试每个关键步骤前，不要直接给出完整实现。
```

### 重建数学证明

```text
$ai-learning-coach 帮我重建“根号 2 是无理数”的证明。
先补充我缺少的前置知识，再用一个相关证明检查我的理解。
```

### 精读论文

尽可能附上论文或链接，并说明阅读目标：

```text
$ai-learning-coach 帮我批判性阅读这篇论文。区分作者报告的内容与我们
能从正文检查的证据，并教我评估核心主张。
```

论文学习可以围绕理解、批判、复现、比较或应用展开。教练会明确自己只获得了元数据、摘要、部分正文还是完整主文，不会假装读过无法访问的内容。

### 分析社会现象

```text
$ai-learning-coach 教我如何分析生育率下降，避免把相关性直接当作因果关系。
比较不同机制，以及每种机制能够预测的证据。
```

### 复习主题

```text
$ai-learning-coach 检查我对 TCP 拥塞控制还记得多少。
从闭卷提取开始，并根据我的错误调整复习。
```

## 教学模式

Skill 会按当前目标选择模式，并在任务变化时重新分类：

| 模式 | 适用内容 | 常见学习活动 |
| --- | --- | --- |
| 实操工程 | 工具、系统、调试和实现 | 构建、检查、预测和诊断 |
| 抽象概念 | 模型、机制、理论和定义 | 解释、比较、分类和应用 |
| 数学论证 | 形式化论证与推导 | 陈述假设、证明步骤和检查边界 |
| 混合模式 | 同时包含上述多种内容的任务 | 在形式理解与实际应用之间切换 |

实际流程会自适应调整，不是固定的八道问题。面对零基础学习者时，教练会先教学并给出一个示范，再要求完成近迁移任务。

## 进度、掌握与复习

接受过提示的回答不能证明独立掌握。只有同时满足以下条件，教练才会声称已经掌握：

- 正确完成一次闭卷回答；
- 在没有关键提示的情况下，完成一个有实质差异的迁移任务。

教练可以根据表现建议之后的提取练习时间。除非你明确提出要求，并且宿主提供可用的提醒工具，否则这些建议不代表已经创建日历提醒。

暂停或更换 Agent 时，可以请求交接：

```text
$ai-learning-coach 创建一份 LEARNING_STATE 交接记录，让我之后继续学习。
```

交接记录只保存有边界的学习进度，不包含来源原文、凭据、权限或隐藏上下文。

## 不适用的情况

如果你只需要完成后的答案、报告、翻译、编辑结果或其他交付物，可以不使用本 Skill。对于涉及人身安全、医疗、法律或财务的决策，它也不能替代有资质的专业人士。

AI Learning Coach 可以组织练习并检查推理，但不能通过一次对话证明长期记忆或现实能力。它不会虚构无法访问的论文内容、引用、工具结果或已经创建的提醒。

## 项目内容

运行时 Skill 位于 `ai-learning-coach/`：

```text
ai-learning-coach/
├── SKILL.md
├── agents/openai.yaml
└── references/
    ├── learning-modes.md
    ├── learning-state.md
    ├── paper-learning.md
    └── social-phenomena-learning.md
```

项目由过程性 Markdown 构成，不是可执行应用。`SKILL.md` 保存共享教学契约；只有当前模式或特化需要的 reference 才会被加载。当前协议版本为 `2.1`，版本 2 交接仍可读取由协议 `2.0` 生成的记录。

如需使用 Agent Skill Author 校验检出目录，可以运行：

```bash
python3 /path/to/agent-skill-author/scripts/validate_skill.py ai-learning-coach
git diff --check
```

校验只能检查包结构和文档完整性，不能单独证明教学效果、宿主发现行为或对所有 Agent 宿主的兼容性。
